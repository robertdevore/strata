Strata’s 0.9 release brings safer local automation, recoverable editing, bounded AI workflows, and improved project browsing. This release uses app version 0.9.0 and includes all changes since 0.8.0.

### What changed

- Added transactional note history, revision-safe updates and restores, stronger autosave/draft protection, and verified backup recovery.
- Hardened the authenticated loopback API, trusted desktop IPC, provider credential storage, and AI write permissions. Oversized mutation responses now roll back before reporting failure.
- Added bounded note/project retrieval and more efficient title, tag, link, and chat-history handling. AI project discovery supports pagination, and overlapping turns cannot write into the same conversation.
- Improved full-library project browsing, wiki-link navigation, revision controls, and sidebar layout. Search no longer forces closed projects open; project toggles work while filtering, including empty results.
- Fixed Quick Open loading layout, clipped search focus borders, and sidebar scrollbar shifts.
- Updated dependencies. The remaining Dependabot PR was already satisfied on main and was closed without merging; npm audit reports zero known vulnerabilities.

### Downloads

- **DMG:** standard drag-to-Applications installation.
- **macOS ZIP:** the same application bundle in an archive.
- **Blockmaps and SHA256SUMS:** companion packaging metadata and SHA-256 integrity checks.
- GitHub also provides source ZIP and tar.gz archives for this tag.

These macOS application downloads are **Intel/x64, unsigned, and not notarized**, matching the previous release’s distribution status. No ARM64, Windows, or Linux binary is included. Quit Strata before replacing the installed application, then relaunch it.

### Upgrade notes

Make a backup before upgrading from 0.8.0. Database migrations are automatic; older versions may refuse a newer database schema. Keep the pre-upgrade backup if you need to return to an older release. The retired Paperclip bridge and legacy clients remain disabled; use the authenticated current CLI/API.

### Verification

356 tests passed, along with formatting, lint, TypeScript checking, and the production build. ZIP integrity and application-bundle equivalence were checked separately. No live user library was used as a test fixture. Signing/notarization and cross-platform installer acceptance are not claimed.
